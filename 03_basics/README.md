
# 概率论 (PyTorch)

> 作者：出自 Nidhogg-max

本 Jupyter Notebook 以 PyTorch 为核心工具，通过模拟离散均匀分布（公平骰子实验）直观展示概率论中的基本概念，尤其是大数定律。利用 `torch.distributions.multinomial` 实现随机抽样，并通过累积频率的可视化，观察样本估计概率随实验次数增加逐步逼近理论值的过程。

---

## 📄 文件说明

- **文件名**：`chapt3.ipynb`
- **内容**：使用 `Multinomial` 分布模拟六面骰子的投掷实验，展示多组实验下各面出现频率的收敛情况，诠释大数定律。

---

## 📖 章节概览

| 节号 | 标题 | 主要内容 |
|------|------|----------|
| 1.1 | 离散均匀分布模拟 | 创建公平概率 `[1/6]*6`，使用 `Multinomial(1, probs).sample()` 模拟单次抽签；尝试不同总次数，理解有放回抽样。 |
| 1.2 | 大数定律的直观展示 | 分别进行 100 次和 10000 次实验，计算各面频率并与理论值 1/6 比较，观察次数越多越接近理论值。 |
| 1.3 | 累积频率可视化 | 进行 500 组实验（每组 10 次投掷），计算每个面的累积频率，用 Matplotlib 绘制收敛曲线，并与理论概率线对比。 |
