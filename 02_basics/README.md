# 微积分基础 (PyTorch)

> 作者：出自 Nidhogg-max

本 Jupyter Notebook 以 PyTorch 为核心工具，介绍微积分中的基本概念及其在代码中的实现，包括导数的数值逼近、自动微分机制、分离计算以及控制流下的梯度计算。通过可视化与代码示例，帮助理解导数、梯度计算图等深度学习预备知识。

---

## 📄 文件说明

- **文件名**：`chapt2.ipynb`（或当前文件名）
- **内容**：导数的数值计算方法、自动微分、分离计算、控制流与梯度，全部基于 PyTorch 张量。

---

## 📖 章节概览

| 节号 | 标题 | 主要内容 |
|------|------|----------|
| 1.1 | 导数和微分 | 使用数值极限法 (`(f(x+h)-f(x))/h`) 逼近导数；定义绘图函数，可视化原函数 `f(x)=3x²-4x` 及其在 `x=1` 处的切线。 |
| 1.2 | 自动微分 | 通过 `.requires_grad_(True)` 开启梯度记录，计算 `y=2·(x·x)` 的梯度并验证 `x.grad == 4x`；标量与非标量变量的反向传播区别。 |
| 1.3 | 分离计算 | 使用 `.detach()` 将张量从计算图中分离，演示 `u` 被视为常数时对梯度的影响。 |
| 1.4 | 控制流的梯度计算 | 即使函数包含 `while` 循环和 `if` 分支，PyTorch 的动态计算图依然能正确追踪并计算梯度，验证 `a.grad == d / a`。 |
