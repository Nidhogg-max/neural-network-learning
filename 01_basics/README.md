# 线性代数基础 (PyTorch)

本 Jupyter Notebook 以 PyTorch 张量操作为核心，从标量、向量、矩阵到高阶张量，逐步演示线性代数中的基本运算，包括创建、加减乘除、转置、降维求和、点积、矩阵-向量积和矩阵乘法。适合作为 PyTorch 入门与线性代数实践相结合的参考资料。

---

## 📄 文件说明

- **文件名**：`linear_algebra_basics.ipynb`（或当前文件名）
- **内容**：使用 PyTorch 实现线性代数基本运算，覆盖张量的创建、形状变换、沿轴求和、累积和、点积与矩阵乘法等。

---

## 📖 章节概览

| 节号 | 标题 | 主要内容 |
|------|------|----------|
| 1.1 | 标量的创建及基本运算 | 用 `torch.tensor` 创建标量，加减乘除，整数与浮点数的自动类型提升，除法始终返回浮点。 |
| 1.2 | 向量的创建和使用 | `torch.arange` 生成向量，索引访问元素，`len()` 与 `.shape` 查看长度。 |
| 1.3 | 矩阵的创建和使用 | 二维张量的创建、转置 `.T`、`reshape` 变换形状，矩阵逐元素比较。 |
| 1.4 | 张量 | 高阶张量的概念，创建三阶张量；张量的加法、乘法（逐元素），标量与张量的运算，运算后形状不变。 |
| 1.5 | 降维 | 使用 `.sum()` 对所有元素求和；通过 `axis` 参数沿指定轴求和，保留或不保留维度。 |
| 1.6 | 非降维求和 | `keepdims=True` 保留轴用于广播除法（归一化）；`cumsum` 计算沿轴的累积和。 |
| 1.7 | 点积 | `torch.dot` 计算两向量点积，等价于 `sum(a*b)`。 |
| 1.8 | 向量积与矩阵乘法 | `torch.mv` 实现矩阵-向量积，`torch.mm` 实现矩阵乘法；强调维度匹配条件。 |
