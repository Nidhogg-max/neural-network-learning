# 线性神经网络与线性回归 (PyTorch)

> 作者：出自 Nidhogg-max

本 Jupyter Notebook 以 PyTorch 为核心工具，从零开始完整实现线性回归模型，覆盖数据生成、模型定义、损失函数、优化算法和训练循环等核心环节。通过对比 `for` 循环与矢量化运算的速度差异，直观展示矢量化加速的效果；利用正态分布可视化解释平方损失的理论依据；并详细解析小批量随机梯度下降的原理与 PyTorch 自动求导机制，最后通过训练验证模型参数能够收敛至真实值。

---

## 📄 文件说明

- **文件名**：`chapt4.ipynb`
- **内容**：生成人造线性数据集，手动实现线性模型、均方损失和随机梯度下降函数，搭建完整的训练与评估流程，并通过详细的代码注释和流程解析帮助理解深度学习基础。

---

## 📖 章节概览

| 节号 | 标题 | 主要内容 |
|------|------|----------|
| 1.1 | 线性回归的基本元素 | 介绍线性模型基本形式，通过矩阵乘法示例解释特征与权重的对应关系；对比 `for` 循环加法与矢量化加法，展示速度差异；可视化正态分布曲线，解释平方损失与噪声假设。 |
| 1.2 | 线性回归的实现 | 生成具有线性关系 + 噪声的合成数据集；实现小批量数据迭代器；随机初始化模型参数；定义线性模型、均方损失函数和小批量随机梯度下降优化器。 |
| 1.3 | 训练与评估 | 搭建训练循环：前向计算 → 损失求和 → 反向传播 → 参数更新 → 每 epoch 评估整体损失；观察损失下降过程，并比较学得参数与真实参数的误差。 |
| 1.4 | 训练流程详解 | 通过代码逐块解析、维度变化表格和详细问答，说明梯度累加、`l.sum().backward()` 的作用、`no_grad()` 的必要性以及参数更新与梯度清零的逻辑。 |
